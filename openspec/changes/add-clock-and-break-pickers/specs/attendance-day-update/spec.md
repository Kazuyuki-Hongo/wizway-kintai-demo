# Spec Delta

## ADDED Requirements

### Requirement: 出勤と退勤を時刻ボタンから選べる

日ごと表の出勤と退勤は、テキスト入力だけに頼ってはならない（MUST NOT）。画面は、カレンダー風のボタン操作で時刻（`HH:MM`）を選べるようにしなければならない（SHALL）。選んだ値は、これまでと同じくその日の出勤または退勤の欄に `HH:MM` で出なければならない（SHALL）。保存時に送る値の形と、退勤が出勤より前なら拒否する契約は変えてはならない（MUST NOT）。

#### Scenario: 出勤をボタンで 10:00 にする

- **GIVEN** 社員1の 2026-11-02 は通常出勤で、出勤 09:00 である
- **WHEN** その日の出勤を、時刻ボタンから 10:00 に選ぶ
- **THEN** 出勤の欄は 10:00 である
- **AND** 退勤と休憩の欄の値は変わらない

#### Scenario: 退勤をボタンで選び、出勤より前なら保存は拒否される

- **GIVEN** 社員1の 2026-11-02 は出勤 09:00、退勤 18:00 である
- **WHEN** その日の退勤を、時刻ボタンから 08:00 に選んで保存する
- **THEN** 保存は成立しない
- **AND** 画面に、退勤は出勤より前にはできない、と出る
- **AND** その日の退勤は 18:00 のままである

#### Scenario: 欠勤のときは出勤・退勤を空のままにできる

- **GIVEN** 社員1の 2026-11-05 は欠勤で、出勤と退勤は空である
- **WHEN** 区分を欠勤のまま表示する
- **THEN** 出勤と退勤は空である
- **AND** 時刻ボタンで値を入れなくても、欠勤の空の契約は保てる

### Requirement: 休憩を長さのタイマーボタンから選べる

日ごと表の休憩は、時刻入力ではなく長さとして扱わなければならない（SHALL）。画面は、タイマー風のボタン操作で長さ（`HH:MM`）を選べるようにしなければならない（SHALL）。既定の長さは 1時間（`01:00`）でなければならない（SHALL）。長さは 1分刻みで直せなければならない（SHALL）。退勤があるときの休憩必須、および出勤から退勤までより長い休憩の拒否は変えてはならない（MUST NOT）。

#### Scenario: 休憩の既定は 01:00 である

- **GIVEN** 社員1の 2026-11-21 は保存済みでなく、区分は通常出勤である
- **WHEN** その日の休憩のタイマー選択を開く、または休憩に初めて値を載せる
- **THEN** 休憩の長さは 01:00 から始まる

#### Scenario: 休憩を 1分刻みで 01:15 にする

- **GIVEN** 社員1の 2026-11-02 は休憩 01:00 である
- **WHEN** その日の休憩を、タイマーボタンで 1分刻みに直し 01:15 にする
- **THEN** 休憩の欄は 01:15 である

#### Scenario: 長さとして長すぎる休憩は保存できない

- **GIVEN** 社員1の 2026-11-02 は出勤 09:00、退勤 18:00、休憩 01:00 である
- **WHEN** その日の休憩をタイマーで 12:00 にして保存する
- **THEN** 保存は成立しない
- **AND** 画面に、休憩は時刻ではなく長さであり、1時間なら 01:00 である、と出る
- **AND** その日の休憩は 01:00 のままである

#### Scenario: 有休・欠勤では休憩は空のままにできる

- **GIVEN** 社員1の 2026-11-05 は欠勤である
- **WHEN** 区分を欠勤のまま表示する
- **THEN** 休憩は空である
