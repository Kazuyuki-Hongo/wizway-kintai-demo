# Spec Delta

## Purpose

ダミー社員1人の、指定した月の勤怠行を、ログインなしで読み取る。行の追加や更新はしない。

## ADDED Requirements

### Requirement: ダミー社員だけを一覧する

システムは、ログインなしで、用意したダミー社員の識別子と表示名だけを返さなければならない（SHALL）。実在の社員、給与、住所、生年月日を含めてはならない（MUST NOT）。

#### Scenario: 一覧は識別子と表示名だけ

- **GIVEN** ダミー社員が3人用意されている
- **WHEN** 社員一覧を要求する
- **THEN** 3人の識別子と表示名が返る
- **AND** 給与、住所、生年月日は含まれない

### Requirement: 指定月の勤怠行を読み取る

システムは、指定したダミー社員と `YYYY-MM` の年月について、その月の各行の日付、区分、出勤、退勤、休憩を返さなければならない（SHALL）。行の追加、更新、削除をしてはならない（MUST NOT）。

#### Scenario: 通常出勤の行は時刻が揃う

- **GIVEN** 対象社員のその月に、通常出勤で出勤と退勤と休憩がある行がある
- **WHEN** その社員とその月の勤怠行を要求する
- **THEN** その行の日付、通常出勤、出勤、退勤、休憩が返る

#### Scenario: 退勤が無い通常出勤は行のまま残る

- **GIVEN** 対象社員のその月に、通常出勤で退勤が無い行が1件以上ある
- **WHEN** その社員とその月の勤怠行を要求する
- **THEN** その行が返る
- **AND** 退勤は空である

#### Scenario: 欠勤の行は時刻を持たない

- **GIVEN** 対象社員のその月に欠勤の行がある
- **WHEN** その社員とその月の勤怠行を要求する
- **THEN** 区分は欠勤である
- **AND** 出勤、退勤、休憩は空である

### Requirement: 不正な指定では行を返さない

年月が `YYYY-MM` でないとき、または社員がダミーに無いとき、システムは勤怠行を返してはならない（MUST NOT）。年月が不正なときは、応答に加えて理由をログに1行残さなければならない（SHALL）。

#### Scenario: 年月の形が違う

- **GIVEN** 社員はダミーにいる
- **WHEN** 年月に `2026/11` を指定して勤怠行を要求する
- **THEN** 勤怠行は返らない
- **AND** ログに、年月が不正である理由が1行残る

#### Scenario: 社員がダミーに無い

- **GIVEN** 指定した識別子のダミー社員が無い
- **WHEN** 年月 `2026-11` の勤怠行を要求する
- **THEN** 勤怠行は返らない
