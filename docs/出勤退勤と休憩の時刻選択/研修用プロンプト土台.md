```
## 仕様の意図
- 出勤・退勤は、テキスト入力だけにせず、カレンダーっぽいボタンから時刻を選べるようにする
- 休憩は時刻ではなく長さ。タイマーっぽいボタンから選べるようにする
- 休憩のデフォルトは1時間（01:00）。1分刻みで調整できる
- 既存の保存契約（退勤は出勤より前にできない、休憩は長さ、欠勤時は空、など）は壊さない

## このターンでやること
/opsx-propose に従い、proposal／design／specs／tasks を先に揃える。実装に入らない。
計画が揃ったら止まってください。
```

**人間の確認（このあと）**
- change 名と、出勤／退勤＋休憩が1本にまとまっているか
- 保存契約を壊さないこと、曜日を作り直さないことが書いてあるか
- 問題なければ、別チャットを開いて「2. OpenSpec apply」へ
