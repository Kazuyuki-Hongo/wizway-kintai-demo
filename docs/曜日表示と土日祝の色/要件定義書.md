# 要件定義書 ― 曜日表示と土日祝の色

- 案件名: 曜日表示と土日祝の色
- 作成日: 2026-11-19
- フェーズ: Spec（OpenSpec なし。成果物はこのフォルダの Markdown）
- 対象リポジトリ: wizway-kintai-demo

## 機能概要 / 目的

日ごとの勤怠表で、日付の横に曜日を出し、土曜日・日曜日・祝日の行は背景色を変える。  
カレンダーを見なくても、週末と祝日が一目で分かるようにする。

## 前提

- 既存のログイン、自分／管理者の権限、月の日ごと表示、1日の保存の流れは維持する
- データは同梱 SQLite のまま。DynamoDB・RDS・本番勤怠は使わない
- 実在の社員名・給与・住所・生年月日は扱わない
- 画面の利用者向け文言は日本語
- この案件では OpenSpec の change／specs は作らない（`docs/曜日表示と土日祝の色/` に残す）

## 対象外

- 出勤／退勤の時刻選択 UI（別案件）
- 休憩長さのタイマー選択 UI（別案件）
- 祝日マスタの管理画面、外部祝日 API 連携
- 土日祝の出勤可否のバリデーション変更（区分・保存ルールは既存のまま）
- 合計（出勤日数・実働・超過・退勤なし件数）の計算変更
- CSV 出力の列追加や曜日列
- API／DB スキーマの変更
- OpenSpec の change／specs への登録
- `template.yaml` の新リソース

## 用語

| 用語 | 意味 |
|------|------|
| 曜日表示 | 日付セルに、日付の横へ出す日本語の曜日（日〜土） |
| 土日祝の背景色 | その日が土曜、日曜、または日本の国民の祝日のとき、行全体に付ける背景色 |
| 国民の祝日 | このデモで使う固定一覧に載っている日付。振替休日・国民の休日も含む |

## ユースケース（正常系）

### UC1: 曜日が見える

1. ログインした本人（または管理者）が、対象社員の月の日ごと画面を開く
2. 各日の日付セルに、日付と曜日が並んで見える（例: `2026-11-02（月）`）

### UC2: 土曜の行が分かる

1. 2026-11 を開く
2. `2026-11-07`（土）などの土曜の行は、平日と違う背景色になっている

### UC3: 日曜の行が分かる

1. 2026-11 を開く
2. `2026-11-01`（日）などの日曜の行は、平日と違う背景色になっている

### UC4: 祝日の行が分かる

1. 2026-11 を開く
2. `2026-11-03`（文化の日）と `2026-11-23`（勤労感謝の日）の行は、平日と違う背景色になっている
3. 祝日が平日でも、祝日用の背景色になる

## UI 要件

- 日付列の見出しは「日付」のままとする
- 日付セルの表示は `YYYY-MM-DD（曜）` とする。曜は `日` `月` `火` `水` `木` `金` `土`
- 例: `2026-11-03（火）`、`2026-11-07（土）`
- 曜日の算出は、画面側で `work_date`（`YYYY-MM-DD`）から行う
- 行の背景色:
  - 平日（月〜金）かつ祝日でない: 既存どおり（特別な背景色なし）
  - 土曜かつ祝日でない: 薄い青系（例: `#e8f1fb`）
  - 日曜、または祝日: 薄い赤系（例: `#fdecee`）
- 同じ日が土曜かつ祝日のときは、日曜・祝日と同じ薄い赤系を使う
- `aria-label`（区分・出勤など）は、これまでどおり `YYYY-MM-DD` 始まりのまま変えない
- 保存ボタンの文言も、これまでどおり日付（`YYYY-MM-DD`）のまま変えない

## API 要件

- 変更しない。月取得・1日保存・合計・CSV・編集履歴の契約はそのまま

## データ

- DB・シードは変えない
- 国民の祝日は、画面側の固定一覧（少なくともデモ既定の 2026 年をカバー）で判定する
- 一覧に無い年の日付は、土日の判定だけ行い、祝日扱いにはしない

## 非機能

- 合計計算・CSV・演習用テーブルの契約は変えない
- SAM の `template.yaml` を大きくしない（新リソースを足さない）
- 外部パッケージの追加はしない（祝日判定は固定一覧で足りる）

## テスト観点（概要）

- 2026-11-02 の日付セルに `（月）` が出る
- 2026-11-07 の行に土曜用の背景色クラス（または同等の印）がある
- 2026-11-01 の行に日曜・祝日用の背景色クラスがある
- 2026-11-03・2026-11-23 の行に日曜・祝日用の背景色クラスがある
- 既存の保存・合計・ログイン系 E2E が、日付セル文言の変更後も通る

## 受け入れの目安

1. サンプル海原でログインし、2026-11 の表で各日に曜日が見える
2. 土曜の行と日曜の行の背景色が、平日と違う
3. 2026-11-03 と 2026-11-23 の行の背景色が、平日と違う（祝日）
4. 区分・出勤などの入力と保存は、これまでどおり動く

## 確定事項（Spec で固定）

1. 表示形式は `YYYY-MM-DD（曜）`
2. 土曜は薄い青、日曜と祝日は薄い赤。土曜かつ祝日は薄い赤
3. 祝日は画面側の固定一覧。API／DB は変えない
4. OpenSpec 登録はこの案件の対象外
5. 時刻選択・休憩タイマー選択はこの案件の対象外
